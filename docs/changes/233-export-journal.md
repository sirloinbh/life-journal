# Add journal entries and their item links to export and restore (#233)

Export and restore did not know the journal tables (#210, #211). A backup lost the entries, and a restore's `DELETE FROM items` cascaded into `journal_entry_items`, dropping every link.

| File                                                       | Change                                                                                                                                                                                                                                                                                                                  |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backend/src/export.ts`                                    | `journal_entries` and `journal_entry_items` added to `EXPORT_TABLES`, after `item_logs` and before `audit_log`.                                                                                                                                                                                                         |
| `backend/src/restore.ts`                                   | Strict row schemas; both tables optional (missing means empty). Checks: one entry per date, unique links, a link's entry and item are in the file and the item was completed on the entry's date. Links and entries are deleted before `items`, inserted after `items`, and the `journal_entries` id sequence is reset. |
| `frontend/src/restore-file.ts`, `frontend/src/restore.tsx` | The confirmation and the result show journal entry and entry link counts.                                                                                                                                                                                                                                               |
| `docs/export-format.md`                                    | Both tables documented.                                                                                                                                                                                                                                                                                                 |
| Tests                                                      | Unit and integration tests for export, restore, round trip, the refused files, and an older file without the tables.                                                                                                                                                                                                    |

A file from before this change still restores, with no entries.
