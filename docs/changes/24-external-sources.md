# #24 분야별 외부 정보 소스 조사

- 이슈: [#24](https://github.com/sirloinbh/life-journal/issues/24)
- 브랜치: `docs/24-external-sources`

## 목적

요구사항 "소스 api가 있으면 활용"에 쓸 소스를 정한다. 앱 코드는 바꾸지 않는다.

## 변경 — 2026-10-31

- `docs/research/external-sources.md`: 분야별 쓸 소스, 쓰지 않는 이유, 약관 조건, 저장 방식, API 키 보관, 조사 한계.
- 사용자 결정을 이슈 댓글에 기록하고 구현 카드를 등록했다.
- 처음 후보였던 알라딘은 종료됐고 네이버 책 검색도 종료된 것으로 보여 YES24를 조사에 더했다. 교보문고는 사용자가 우선으로 정했지만 공개 API를 찾지 못해 사용자 결정대로 YES24로 정했다.

## 검증

- 문서만 바꿔 앱 테스트는 추가하지 않았다.
- `npm run format:check`: 통과.
- 알라딘 공지, YES24 약관, 카카오 운영정책 제4조 제10호는 원문 페이지를 다시 읽어 확인했다. 나머지 약관의 한계는 문서의 "조사의 한계"에 적었다.
- 한도와 제공 필드는 키가 없어 실제 호출로 확인하지 못했다. 구현 카드에서 확인한다.
