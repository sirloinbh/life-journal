# #130 Bump Lighthouse CI to drop the vulnerable basic-ftp

- Issue: [#130](https://github.com/sirloinbh/life-journal/issues/130) (parent [#127](https://github.com/sirloinbh/life-journal/issues/127))
- Branch: `chore/130-lhci-0.16.1`
- Replaces Dependabot PR [#119](https://github.com/sirloinbh/life-journal/pull/119)

## Changes — 2026-11-18

`basic-ftp@5.3.1` came in only through `@lhci/cli@0.16.0` → `proxy-agent@6` → `pac-proxy-agent@7` → `get-uri`. Dependabot alert #13 ([GHSA-5pm8-86m8-9m6r](https://github.com/advisories/GHSA-5pm8-86m8-9m6r)) and `npm audit` (two more `basic-ftp` advisories, rated high) cover `basic-ftp <= 6.2.3`. `@lhci/cli` 0.16.1 moves to `proxy-agent` 8, which brings `basic-ftp` 6.2.6. Lighthouse CI is a dev-only tool that is run by hand with `lighthouserc.json`; the app does not ship it.

- Root `package.json`: `@lhci/cli` `0.16.0` → `0.16.1` (`npm install --ignore-scripts --save-exact`; the user approved the package change).
- `package-lock.json`: started from Dependabot PR #119's lockfile and ran `npm install --ignore-scripts` on top of main. The result is #119's lockfile plus the `minimatch` 11.0.4 override from #128 and main's frontend `zod` entry. #119's branch was behind main and conflicted with #128, so we did not merge it directly.
  - Upgraded: `@lhci/cli` and `@lhci/utils` 0.16.1, `proxy-agent` 8.0.3, `pac-proxy-agent` 9.1.1, `basic-ftp` 6.2.6, `@puppeteer/browsers` 3.2.7, and their `yargs` family.
  - New: `proxy-agent-negotiate` 1.1.0 and `quickjs-wasi` 3.7.0, both MIT, published by the `proxy-agent` maintainer (`quickjs-wasi` also by Vercel).
  - Removed: `@tootallnate/quickjs-emscripten`.
- `docs/next-steps/README.md`: removed the #119 line.

## Verification

- `npm ls proxy-agent basic-ftp minimatch --all`: `basic-ftp` 6.2.6 (patched from 6.2.4), no invalid or missing entries, and the ESLint packages still use `minimatch` 11.0.4.
- `npm audit`: `basic-ftp` and `minimatch` are no longer listed. `picomatch` remains (outside this card).
- `node node_modules/@lhci/cli/src/cli.js --version`: `0.16.1`. `lhci healthcheck` passed, and `lhci collect` on the built `frontend/dist` ran Lighthouse on `index.html` and `offline.html` without errors. The `.lighthouseci/` output was deleted afterwards (it is gitignored).
- `npm run check`: format, lint, contract check and typecheck passed. The backend DB integration tests failed with `ECONNREFUSED 127.0.0.1:5432` because the local PostgreSQL service was stopped and could not be started without admin rights.
- Without `TEST_DATABASE_URL`: `npm test` passed (backend 143 passed, 22 DB tests skipped, 0 failed; frontend 164 passed, 3 skipped), `npm run test:skills` 4 passed, `npm run build` passed. The DB tests run in the PR CI.
